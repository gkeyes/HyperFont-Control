# 使用与迁移

## 安装和升级

下载并在 Root 管理器刷入 `HyperFont-Control-v1.0.0.zip`，然后手动重启。安装包不附字体。不要同时启用 MFGA 或其他字体覆盖模块。

覆盖升级保留 `/data/adb/hyperfont-control` 中的字体库和设置，并重建最近提交的配置。未提交草稿不参与升级生效。重建校验失败会中止安装；不要忽略安装错误。

## 导入字体

“字体库”文件选择器支持一次选择多个 TTF、OTF、TTC 或 OTC 文件，按顺序导入。大文件可先放到 `/sdcard/Download/`，再使用“从手机 Download 文件夹直接导入”。系统会识别字体面、真实字重、斜体和可变轴。

多个静态文件仍作为独立资源显示；进入相应分类选择“静态多字重”，为每个文件指定对应的逻辑字重。不会自动按文件名分组。导入成功后，字体以内容哈希保存到 `/data/adb/hyperfont-control/library/`，以后不依赖 Download 中的原文件。

如果关闭面板中断导入，可以使用“清理未完成导入”。此操作也会取消其他面板正在进行的分块导入，已入库字体和配置保留。超过 24 小时无活动的上传会在新建上传时自动清理。

## 字重设置

四个分类可以独立使用系统字体、可变字体或静态多字重。中文只接管汉字及相关标点，英文分类接管相应拉丁字符，原生其他语言与表情继续补字。

可变字体：选择正体文件，有真实斜体时另选斜体。九档模式下，左侧是应用请求的逻辑字重，右侧是字体实际使用的 `wght` 值。例如逻辑 400 → 450，表示常规文字使用源字体 450 轮廓。映射必须在真实轴范围内且不能逆序；调整常规档后也应检查其余档位的关系。连续模式让系统按可变轴选择；切换模式会保留自定义映射。

静态字体：有哪个实际字重文件就配置哪个，不能只改标签制造不存在的轮廓。例如锤子黑体六个文件可配置 100、300、400、500、700、900。选择“最近字重”后缺少的 200、600、800 由 Android 匹配，具体选择遵循系统匹配规则；这不是插值生成新的字重。选择“缺档拒绝”则需要补齐要求的档位。

等宽分类应选真正的等宽字体。如果选 Anthropic Sans 等比例字体，数字或代码列宽不会自动对齐。字体本身的行距和轮廓保持原样。

## 保存、生效与恢复

“保存草稿”只保存编辑；“提交更改”才生成待生效配置。提交时会校验字体、XML 和 Android 实际解析结果，成功后由你手动重启。

“字体覆盖已挂载”表示当前读取到的字体表和字体文件内容符合生成清单；应用自带字体或独立绘字仍需实际观察。顶部“已暂停这份字体配置”表示上次尝试没有完成 Android 开机，启动保护已跳过同一份配置。先调整或重新提交，再手动重启重试。

如要恢复，在“诊断与恢复”选择“恢复系统字体”，提交后手动重启。字体库保留。完全卸载则由卸载脚本清理本模块拥有的数据目录，临时覆盖在重启后消失；请在卸载前自行保留需要再次导入的源字体。

遇到卡住的那次启动，仍需手动重启或使用 Root 管理器安全模式停用模块。启动保护在下一次执行模块启动脚本时生效，不会主动重启手机。强制在 Android 开机完成前重启，也可能触发保护。

## 导出与迁移

配置导出保存到 Download。配置内的字体 ID 是内容哈希，不包含字体文件。迁移到另一台设备时，先导入相同字体文件，再导入配置、检查并提交；不要直接复制上一台设备生成的 XML 或系统基线。

系统更新导致指纹或原始字体表变化时，模块停止覆盖。恢复系统字体并重启后，使用“重新识别系统”，然后重新提交配置。错误诊断可在面板导出；分享前检查其中的设备信息。
