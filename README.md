# HyperFont Control

支持可变字体与静态多字重的 Android Root 字体模块，通过手机上的分页 Web 面板修改设置。首次正式发布：**1.0.0**；**2.0.0** 重新设计了 Web 面板（液态玻璃风格）。

[下载正式版](https://github.com/gkeyes/HyperFont-Control/releases/latest) · [使用教程](docs/user-guide.md) · [构建说明](docs/building.md) · [实现与覆盖边界](docs/architecture.md) · [Web API](docs/web-api.md)

## 能做什么

- 中文、无衬线英文、衬线英文、等宽英文分别设置，也可分别沿用系统字体。
- 读取可变字体的真实轴范围；支持连续字重和 100–900 九档映射，支持独立斜体文件。
- 导入多个静态字体文件或 TTC/OTC 字体面，逐档指定字重；缺档可拒绝提交或交给 Android 匹配最近字重。
- 根据当前 ROM 的字体配置生成覆盖，保留其他语言、表情与图标的系统补字。
- 提供草稿、配置导入导出、提交、恢复系统字体、字体库和诊断页面。
- 配置提交后由用户手动重启生效，不在运行中的应用里热替换字体。

模块本身不包含字体，不提供字体下载，也不启动网络服务。请自行导入你有权使用的字体。

## 安装条件

- Android 10+，arm64 或 x86_64。这里只表示构建与代码支持范围，不能视作所有设备都已验证。
- Root 管理器支持模块启动脚本。KernelSU 使用 `post-mount.sh`，Magisk 使用 `post-fs-data.sh`。旧版 KernelSU 如果不执行 post-mount，本模块不会生效。
- Web 面板需要支持 KernelSU `ksu.exec` 接口的宿主。Magisk 用户需要另备兼容宿主。
- HyperOS 默认文字字重适配需要可用的 Zygisk 实现，例如 Zygisk Next。其他字体覆盖不依赖 Web 面板持续打开。
- 内核及 Root 域允许 tmpfs、bind mount 与字体安全标签。此模块自己挂载，不依赖 MetaModule。
- 先卸载其他字体覆盖模块并重启，再安装本模块，避免多份字体表相互覆盖。

模块生命周期遵循 [KernelSU 官方说明](https://kernelsu.org/guide/module.html)，Web 接口遵循 [KernelSU WebUI 说明](https://kernelsu.org/guide/module-webui.html)。

## 第一次使用

1. 在 Root 管理器安装 Releases 中的 ZIP，手动重启。
2. 打开模块 WebUI，在“字体库”导入字体。大文件可以从手机 Download 目录直接导入。
3. 在“字体设置”选择分类、字体和字重，检查配置后提交。
4. 手动重启，在通知、设置、桌面和常用应用里确认效果。

已有 HyperFont 用户可以覆盖安装，导入字体和已提交设置会保留；安装器按新版规则重建已提交配置，不会自动启用尚未提交的草稿。升级后仍需手动重启。

## 1.0.0 修复

- **启动保护：** 挂载前记录尝试，Android 完成开机后确认。如果未完成开机，下一次启动跳过同一份配置，保留系统字体。用户修改或重新提交后才能重试。不会自动重启，也不保证能即时挽救已经卡住的那次开机。
- **导入恢复：** 自动回收 24 小时没有活动的上传；字体库提供“清理未完成导入”，可以处理关闭面板后遗留的上传，不删除已导入字体。
- **状态校验：** “已挂载”核对字体表和实际字体文件内容，空文件和同大小的损坏文件均不能通过。共享同一文件的路径只计算一次内容哈希。

## 验证范围

发布前的 0.1.8 基线已经在一台 HyperOS 4 / Android 17 / arm64 设备重启运行；锤子黑体六档配置处于活动状态，桌面、微信和 Play 进程可观察到生成字体映射。此前也用 Android 实际解析器和原生选字检查验证过可变苹方与 Anthropic Sans2 的配置路径。

**1.0.0 新增修复以仓库测试、静态检查、两架构构建和安装包校验为发布依据；1.0.0 的实际刷入、启动保护触发与重启后界面效果尚未在手机验收。** Actions 构建日志与 Release 构建报告提供对应源码记录。进程加载字体不能证明每一个控件都使用了它。

已知边界：应用自带字体、网页 `@font-face`、游戏字形图集不由系统字体表控制；字体行距不会被自动统一；多个静态文件可批量导入，但暂不自动合并成一个字体家族或自动填充字重表。指定比例字体到等宽分类也不会自动变为等宽字体。

若异常启动，先用 Root 管理器的安全模式停用模块。不要重新启用已撤回的 0.1.7 测试包；该版本曾产生 Android 解析器拒绝的配置，1.0.0 安装器会用当前规则重新生成已提交配置。
